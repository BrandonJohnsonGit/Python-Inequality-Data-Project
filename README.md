# Python-Inequality-Data-Project
First, I obtained data on GDP and population of countries. I then had to make a scatter plot of GDP vs population and a histogram of GDP per capita. Next, I quantified the inequality in GDP per capita by finding the Gini coefficient and visualize this inequality by making a Lorenz Curve. I then made a choropleth of GDP per capita in each country.

It is first worth noting that the two ".py" files are intended to be run in Spyder, and the ".ipynb" file in JupyterLab. The file "Phy 220 Final" includes the work for the scatterplot and the histogram. Pandas and NumPy were used here. These two visuals, especially the histogram, allow for the viewer to visualize the stark difference in GDP per capita in different nations. The program also calculates the Gini coefficient, which is found to be 0.636024519935164. This suggests a very high level of income inequality. The second file, "2 Phy 220 Final Project" shows a Lorenz Curve. The further the red curve is from the black line, the larger the inequality. This further helps to show the inequality difference. The final file, "3 Phy 220 Final Project", shows a choropleth of GDP per capita in all of the countries. The map is easy to access as the user can hover over the dots with a mouse for more info. The colors also provide a very intuitive way to see the difference. The data files that include economic data about the countries, as well as the data about the locations of the countries are also provided.
